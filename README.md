# GoodDaily

A phone-first progressive web app for tracking the small, daily actions that support your well-being. GoodDaily stores everything on the device in the browser's local storage—there is no account, server, or data collection.

## Included

- Five daily well-being areas with optional notes
- A daily checklist that automatically begins fresh on each new local calendar day
- The option to turn individual areas on or off
- Monthly history, activity totals, and timestamped notes
- A how-to section with gentle inspiration for every area
- Offline support and installability through a web app manifest and service worker

Because records are stored only in the browser's local storage, clearing browser data or using another device starts a separate, empty GoodDaily history.
